## Description

Bring your PDFs, notes, and study passages together in a native workspace for Mac, iPad, and iPhone.

Import PDFs into a local library, organize them into collections, and return to your last reading position. Read and search documents, highlight text, write and edit page annotations, and keep document notes alongside your reading. On compatible iPads, write with Apple Pencil. Finger drawing is available on iPad and iPhone.

Recognize text in scanned pages and create a searchable PDF copy. Export documents and notes, or transfer your active library with a portable backup.

Study offline with source-based summaries, flashcards, and document questions. On compatible devices, optional Apple on-device AI selects verified source quotations. Extractive study remains available when the local model is unavailable. Check the linked source page for context.

No account or server API key is required. Your library is stored on your device. Backups and exports go to locations you choose. Automatic cloud sync is not included.

## Review notes draft

No review login, API key, purchase, or external account is required. Launch the app and select **Explore a sample** from the empty library. This creates a small original PDF locally so the main reading/study flow can be reviewed without external files or network access.

1. Open the sample. Navigate between pages and search for a word visible in the document.
2. Open Notes, enter a sentence, switch away, and reopen it to verify saving.
3. Select PDF text and choose Highlight. Use Write on PDF to draw directly on the page, zoom while writing, and verify automatic saving. Use Tools → Edit annotations on page for advanced annotation editing.
4. Open Study. Review source-based summary/flashcards and ask a question answered by the sample. Source links return to pages. Extractive mode is the default fallback. Optional on-device AI may be unavailable on review hardware; it is not required to use the feature.
5. Use Tools to recognize text or export. Searchable export creates a flattened copy and explains that links/forms/bookmarks are omitted.
6. Open Library options → Library backup to export a backup; import into an empty library to test transfer. Existing IDs are kept rather than overwritten.

The app imports copies of files selected through the system picker. Removing a library document retains a local recovery copy and does not delete the original selected file. Review notes should be checked against the final button labels before submission.
