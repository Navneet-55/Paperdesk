Paperdesk support

A local workspace for PDFs, notes, and source-based study.

Release draft: this page is prepared locally and is not yet hosted. Confirm the final signed app and legal seller identity before publication.

Contact Navneet

Email kvnavneet@gmail.com for Paperdesk support or privacy questions. Do not attach private PDFs or notes unless you choose to share them.

Start reading

Choose Import PDF and select a file, or choose Explore a sample in an empty library. Paperdesk copies imports into its library. Select a document, use page controls to navigate, and press Find or Return after entering a search.

Write and save

Document notes save automatically. Choose Write on PDF to write directly on the visible page. Ink saves automatically; Done returns to reading. Pinch or use the reader controls to zoom while writing. Use Tools → Edit annotations on page for text boxes and existing-annotation changes. Compatible iPads support Apple Pencil. Finger drawing is available on iPad and iPhone. Check any save error before closing the app.

Scans and study

Scanned pages may need Recognize text before search can find their contents. OCR accuracy varies with image quality and language. Offline Study uses source passages; check the linked page to verify context. Optional on-device AI requires compatible hardware, software, enabled Apple Intelligence, and a ready local model. Extractive study remains available without it.

Export and move your library

Export PDF or notes from Tools. Searchable PDF export creates a flattened copy; review its in-app explanation before using it for forms, links, or bookmarks. Library backup exports active documents, notes, collections, reading positions, drawings, and recognized-text caches. Keep backups somewhere safe. Importing a backup adds new document IDs and leaves existing documents unchanged; it does not synchronize newer edits.

Removed documents and storage

Removing a document from the library keeps a local recovery copy and leaves your selected original unchanged. Current backup exports do not include the recovery archive. If you need permanent erasure or recovery assistance, use the publisher’s support channel once it is available; avoid deleting app data before making the backups you need.

Report a problem

Provide the app version, device model, OS version, what you expected, and the steps that reproduce the issue. Include a redacted screenshot if useful. Do not send confidential PDFs, personal notes, passwords, or API keys. No account or API key is needed to use Paperdesk’s local features.
